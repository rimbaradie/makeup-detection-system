# Makeup Detection System

**An AI-driven multi-platform solution for intelligent makeup and skincare recommendations.**

---


## Overview
The **Makeup Detection System** is an innovative platform that helps users select suitable makeup products by analyzing skin type and facial features using AI technology, as recommended by dermatologists.  

The system leverages the **Face++ Camera API** to provide accurate, percentage-based skin type detection, delivering personalized and data-driven makeup recommendations.  

This project bridges traditional product selection methods with intelligent AI-driven solutions, enhancing both accuracy and user experience.  

---

## Features
- **AI-Powered Skin Analysis** – Detects facial features and skin type precisely.  
- **Dermatologist-Recommended** – Offers clinically approved product suggestions.  
- **Multi-Platform Support** – Responsive web app and native Android application.  
- **Weather-Adaptive Recommendations** – Integrates real-time weather data for optimal skincare guidance.  
- **User-Friendly Interface** – Built with modern UI/UX principles for smooth interaction.  

---

## Technical Architecture
- **Modular Design** – Components are independent, scalable, and maintainable.  
- **Real-Time Data Integration** – Combines facial analysis with dynamic weather information.  
- **Cross-Platform Development**:  
  - **Web App:** JavaScript, PHP, HTML, CSS, Bootstrap  
  - **Android App:** Java (Android Studio)  
- **AI Integration:** Face++ Camera API for facial recognition and skin analysis  

---

## Technologies Used
- **Front-End:** HTML, CSS, JavaScript, Bootstrap  
- **Back-End:** PHP  
- **Mobile:** Java, Android Studio  
- **API:** Face++ Camera API  
- **Tools:** VS Code, Android Studio
