Managing User Accounts

Step 1: Login to the Admin Dashboard

Enter your admin credentials and go to the main dashboard.

Step 2: Access the User Management Section

From the menu, click on "Users" to open the user management table.

Step 3: Add a New User

  • Click the "Add User" button.
  • Fill out the form with user details like name, email, password, and role.
  • Click "Save" to create the new user account.

Step 4: Edit Existing Users

  • Find the user in the table and click the "Edit" icon.
  • Update the fields you want to change (e.g., email or role).
  • Click "Update" to save changes.

Step 5: Delete a User

  • Click the "Delete" icon next to the user you want to remove.
  • Confirm the deletion in the popup dialog.
  • The user will be permanently removed from the system.

Step 6: Search or Filter Users

Use the search box to find specific users quickly by name, email, or role.
